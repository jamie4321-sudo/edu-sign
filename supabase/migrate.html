구글시트 → Supabase 데이터 이전

현재 구글시트(GAS)에 있는 세션 · 명단 · 서명 · 사진 기록을 Supabase로 복사합니다. 여러 번 실행해도 안전합니다(같은 id는 덮어씀).

실행 전 체크
  1. supabase/schema.sql 을 Supabase SQL Editor 에서 실행했나요?
  2. js/config.js 의 supabase.url / supabase.anonKey 를 채웠나요?
  3. 기존 endpoint(구글시트)는 그대로 두세요 — 여기서 원본으로 읽습니다.

※ 서명이 구글드라이브에 저장돼 있던 건(아주 긴 서명)은 드라이브 이미지 링크 형태로 옮겨집니다. 사진도 기존 드라이브 링크를 그대로 복사합니다(계속 보임). 새로 올리는 사진부터 Supabase Storage 에 저장됩니다.
